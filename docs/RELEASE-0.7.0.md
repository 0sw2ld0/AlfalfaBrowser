# AlfalfaBrowser 0.7.0

- Primera versión con el nombre AlfalfaBrowser. El paquete conserva `cuybrowser` y añade `alfalfabrowser` como segundo comando de la misma CLI. Los perfiles existentes y el registro MCP conservan sus nombres.
- Los clics y movimientos del agente muestran la hoja de AlfalfaDesktop de 18 px en las ventanas que abre con su propio perfil. La punta coincide con el punto de interacción. Las capturas de página excluyen la hoja. [PR #12](https://github.com/0sw2ld0/AlfalfaBrowser/pull/12)

Las descargas incluyen los ejecutables autónomos con sus nombres `cuybrowser-*`, el paquete `cuybrowser-0.7.0.tgz` para Node.js 20 o superior y `SHA256SUMS` para verificar los archivos.
