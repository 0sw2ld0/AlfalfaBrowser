# AlfalfaBrowser 0.8.0

- Instala un único comando, `alfalfabrowser`. Las descargas y el paquete también usan el prefijo `alfalfabrowser`. Las versiones ya publicadas conservan sus archivos.
- Los perfiles existentes siguen en `~/.cuybrowser`. Se conservan las variables `CUYBROWSER_*` y el identificador del servidor MCP.
